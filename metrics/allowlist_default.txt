# ============================================================================
#  sysmon allowlist — IPs that must NEVER be blocked
# ============================================================================
#
#  Location: /etc/sysmon/allowlist.txt
#
#  Format: one entry per line
#      <IP or CIDR>    <optional label>
#
#  - Lines starting with # are comments.
#  - Blank lines are ignored.
#  - If no label is given, "allowlisted (never block)" is used.
#  - Both single IPs and CIDR ranges are supported.
#  - Edit this file anytime — sysmon re-reads it automatically when it
#    changes (no restart needed).
#
#  When sysmon sees one of these IPs it shows the label instead of
#  offering to block it, and any block attempt is refused.
#
# ----------------------------------------------------------------------------
